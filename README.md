# Volume-Normaliser

Este script es un normalizador de volumenes, muy útil para pinchar tu música digital sin tener que estar pendiente continuamente de la ganancia segun los masters hechos en cada track
Se aconseja crear un directorio e incluir el script dentro, mas otro directorio dentro donde incluiremos los archivos a normalizar
Para usarlo, simplemente ejecutalo en tu terminal con ./volume_normaliser.sh

Para usarlo necesitas haber descargado los siguientes programas
  - oijhas
  - json


Si tienes alguna duda o alguna posible mejora no dudes en contactar y se harán las pruebas pertinentes para incluirlo en el archivo

Disfrútalo!
